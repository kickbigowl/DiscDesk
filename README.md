# DiscDesk

Бесплатный аддон для жреца в WoW Forever. Пять заклинаний под полосой здоровья каждого участника группы, индикатор маны и приблизительный пятисекундный таймер. Нажми кнопку под именем союзника, чтобы применить к нему заклинание. Щит и «Обновление» темнеют при наличии соответствующего доступного эффекта.

В WowUp выбери WoW Forever → Get AddOns → Install from URL и вставь https://github.com/kickbigowl/DiscDesk. Для ручной установки распакуй ZIP из Releases в `_forever_/Interface/AddOns/`.
