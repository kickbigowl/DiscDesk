# DiscDesk

Бесплатный аддон для жреца в WoW Forever. Пять заклинаний под полосой здоровья каждого участника группы, индикатор маны и приблизительный пятисекундный таймер. Нажми кнопку под именем союзника, чтобы применить к нему заклинание. Открой настройки через ПКМ по миникарте и перенеси до пяти заклинаний из книги в пустые ячейки вне боя. ПКМ очищает ячейку. Один набор применяется ко всем союзникам. Для щита отслеживается «Ослабленная душа», для остальных заклинаний — одноимённый положительный эффект. При доступных данных на иконке видны круговой отсчёт и секунды. Полоса ХП бледнеет, когда все назначенные заклинания за пределами дальности.

В WowUp выбери WoW Forever → Get AddOns → Install from URL и вставь https://github.com/kickbigowl/DiscDesk. Для ручной установки распакуй ZIP из Releases в `_forever_/Interface/AddOns/`.
